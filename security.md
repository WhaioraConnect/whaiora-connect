# Security Policy

At Whaiora Connect Ltd, we take the security of our systems and user data seriously.
We welcome responsible disclosure of security vulnerabilities.

## Reporting a Vulnerability

If you believe you have discovered a security issue, please report it as soon as possible.

📧 Email: maxwell@whaioraconnect.nz  
🔐 PGP Key: https://whaioraconnect.nz/.well-known/pgp-key.txt

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Any supporting material (screenshots, logs, PoC)

## Scope

The following are **in scope**:
- Web applications hosted under `whaioraconnect.nz`
- APIs and backend services operated by Whaiora Connect Ltd

The following are **out of scope**:
- Denial of Service (DoS/DDoS)
- Social engineering or phishing
- Physical security issues
- Vulnerabilities in third-party services outside our control

## Safe Harbour

We will not pursue legal action against researchers who:
- Act in good faith
- Avoid privacy violations and data destruction
- Do not exploit issues beyond proof-of-concept
- Allow reasonable time for remediation before public disclosure

## Response Timeline

- Initial response: within **5 business days**
- Status update: within **10 business days**
- Fix or mitigation: as soon as reasonably possible

## Bug Bounty & Rewards

At this time, Whaiora Connect Ltd does not offer a paid bug bounty programme.

However, we value responsible disclosure and may offer:
- Public acknowledgement (with permission)
- A letter of appreciation
- Priority engagement for future security initiatives

We are open to establishing a formal bounty programme as the platform matures.

## Security Standards Alignment

Whai Ora Connect aligns its security practices with the principles of:

- **ISO/IEC 27001** (Information Security Management)
- **NIST Cybersecurity Framework (CSF)**

This includes:
- Risk-based security decision-making
- Least-privilege access control
- Secure configuration and change management
- Logging, monitoring, and incident response procedures
- Regular review of security controls

While Whaiora Connect Ltd is not currently ISO 27001 certified, security controls are
implemented proportionate to organisational size, risk profile, and system criticality.
